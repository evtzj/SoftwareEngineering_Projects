# 网站优化说明

本轮沿用中期报告中的四个代表功能，把结果展示、复盘和数据恢复接到同一条操作流程中。

| 报告内容 | 本轮改进 | 页面入口 |
| --- | --- | --- |
| 多语言代码分析 | 点击语言查看文件；按路径、语言和解析状态筛选；文件与函数明细每页 40 条；从文件定位其函数 | 代码统计 → 统计报告、文件明细、函数明细 |
| 报告历史与比较 | 导入报告 JSON；整体备份和恢复历史；突出文件、代码行和函数数量变化；更换报告后清除旧对比结果 | 代码统计 → 历史与对比 |
| 运算练习与错题 | 自动保存题目、答案和页码；刷新恢复；Enter 切换下一题；分别复盘答错、未答、答对题；按运算筛选后重练 | 运算练习 → 在线作答、错题本 |
| 个人档案与学习计划 | 计划进度、搜索与逾期筛选；桌面双栏、手机单栏；首页展示真实记录并提供继续学习入口 | 首页、个人档案 → 学习计划 |

## 实现说明

统计仍以 `CodeReport` 为统一结果对象，图表、明细和导出读取相同的数据。明细筛选只改变显示范围，导出的报告保留完整统计。JSON 导入先确认格式和口径，再从文件记录重新汇总；历史快照继续使用独立副本。

练习保存题目、答案、规则和时间，不重复保存整份批改明细。恢复时调用原批改器重建结果，避免演算和批改使用两套规则。输入后延迟写入，切换页面时立即保存；未答题继续独立计数，不进入错题本。计时沿用从练习生成到交卷的经过时间，离开页面的时间也计入。

首页与学习记录由 `activity.js` 汇总已有记录，累计正确率按题量加权；计划逾期状态由当天日期推导。所有数据继续保存在当前浏览器，页面没有新增账号或服务端数据库。

## 演示顺序

1. 生成一份练习，填两道题后刷新，展示答案和页码恢复，再从首页继续作答。
2. 交卷后切换“答错”“未答”，打开错题本查看计算过程，再按运算筛选重练。
3. 载入五语言示例，点击语言图进入文件列表，再点击函数数量定位定义位置。
4. 导出 JSON，在历史页重新导入，展示相同指标；保存两份报告后查看变化。
5. 新建带日期的学习计划，切换完成和逾期筛选，展示首页与计划页的数据联动。
