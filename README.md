# SoftwareEngineering_Projects

软件工程课程设计，包含个人主页、代码量统计和四则运算练习三个模块。

## 运行

需要 Node.js 18 或更高版本。

Windows 下双击 `启动网站.bat`，浏览器会自动打开页面。运行期间保留命令行窗口。

也可以在项目目录运行：

```bash
npm start
```

访问 <http://127.0.0.1:3000>。网站运行无需安装 npm 依赖；请通过本地服务访问，不要直接打开 `web/index.html`。

## 功能

### 个人主页

- 展示个人简介、成长足迹和作品成就，适配电脑与手机。
- 可以编辑资料，添加、修改和删除记录。
- 资料保存在当前浏览器，页面底部支持 JSON 备份导出与导入。

初始姓名和经历是示例内容。通过“编辑主页”和记录旁的“编辑”替换即可。如果要让其他电脑也显示自己的资料，可以修改 `web/app.js` 中的 `defaults`；浏览器已保存的资料优先于默认数据。

### 代码量统计

- 支持选择文件、文件夹、拖放文件和粘贴代码。
- 支持 JavaScript、TypeScript、Python、C / C++、Java、HTML、CSS、SCSS、JSON、SQL。
- 分别统计代码行、注释行和空白行，显示语言分布与文件明细，支持导出 CSV。
- 文件在浏览器内读取，自动跳过依赖目录、Git 元数据和构建输出。

统计按物理行计算：混合行归代码，纯注释行归注释，空白行单独计算，末尾换行不额外计一行。Python 三引号字符串按代码计。采用基础词法扫描，不展开宏或外部文件。

### 四则运算练习

- 选择 10、20、100 以内的范围，以及 5、10、20、30 道题。
- 可以组合加、减、乘、除；减法非负，除法整除，乘除法使用九九乘法表。
- 题目不重复，各种运算均匀出现。题目不足时提示减少题量或增加运算种类。
- 支持作答进度、批改、错题重练和最近练习记录。
- 可以下载或打印练习，选择是否附带答案。

## 目录

```text
web/
  index.html              页面入口
  app.js                  页面交互、默认资料与浏览器存储
  logic.js                行数统计、出题与批改
  style.css               样式、响应式布局和打印样式
  assets/                 网站图标
server.mjs                本地静态服务
tests/                    逻辑测试和浏览器测试
preview/                  界面截图
```

## 测试

逻辑测试使用 Node.js 自带的测试工具：

```bash
npm test
```

浏览器测试需要本机安装 Google Chrome。安装开发依赖后，保持本地服务运行，在另一个终端执行：

```bash
npm ci
npm run test:browser
```

目前 11 项逻辑测试和 3 个浏览器流程测试通过。覆盖注释与字符串识别、出题约束、批改、资料保存、文件读取、报告导出和手机布局。

## 小组协作

从 `main` 创建功能分支，完成后通过 Pull Request 合并。主页、代码统计和运算练习可以分别推进。Git 已忽略本地录音、整理笔记、转写环境、依赖目录和测试输出。

后续先补充真实个人资料，再按老师给出的细则扩展功能和课程文档。
